# API Reference

Interactive docs are generated by FastAPI and are the authoritative
source: <http://localhost:8000/docs> (Swagger) or `/redoc`.

Everything below is a summary of that. All routes are prefixed `/api`.

## Authentication

Every endpoint except `/api/health` and the two login routes requires a
bearer token:

```
Authorization: Bearer <access_token>
```

Register or log in to get one. Tokens expire after
`ACCESS_TOKEN_EXPIRE_MINUTES` (default 480 = 8 hours).

```bash
curl -X POST http://localhost:8000/api/auth/register \
  -H 'Content-Type: application/json' \
  -d '{"email":"prof@university.edu","name":"Dr. Ada Lovelace",
       "password":"a-good-password","role":"professor"}'
```

`/api/auth/login` takes an OAuth2 **form** (so the Swagger "Authorize"
button works); `/api/auth/login-json` takes a JSON body. The `username`
field on the form endpoint carries the email address.

### Roles

| Role | Can | Cannot |
|------|-----|--------|
| `professor` | everything | — |
| `ta` | create courses, upload, grade, override, review flags | finalize a grade, delete a course or assignment |

### Ownership

A user only ever sees their own courses. Requesting someone else's
resource returns **404, not 403** — a 403 would confirm that the resource
exists.

## Endpoints

### Auth
| Method | Path | Description |
|--------|------|-------------|
| POST | `/api/auth/register` | Create an account, return a token. 409 if the email is taken. |
| POST | `/api/auth/login` | Form login (OAuth2 password flow). |
| POST | `/api/auth/login-json` | JSON login. |
| GET | `/api/auth/me` | The account behind the current token. |

### Courses
| Method | Path | Description |
|--------|------|-------------|
| GET | `/api/courses` | Your courses, newest first. |
| POST | `/api/courses` | Create a course. |
| GET | `/api/courses/{course_id}` | One course. |
| PATCH | `/api/courses/{course_id}` | Partial update. 400 on an empty body. |
| DELETE | `/api/courses/{course_id}` | Delete the course, its assignments, submissions, grades, and files. **Professor only.** |

### Assignments and rubrics
| Method | Path | Description |
|--------|------|-------------|
| GET | `/api/assignments` | All your assignments. `?course_id=` narrows it. |
| POST | `/api/assignments` | Create. Supply `rubric_json`, or `rubric_raw_text` (AI-extracted), or neither (default rubric). |
| GET | `/api/assignments/{id}` | One assignment. |
| PATCH | `/api/assignments/{id}` | Partial update. A new `rubric_json` is re-validated. |
| DELETE | `/api/assignments/{id}` | Delete it and its files. **Professor only.** |
| GET | `/api/assignments/{id}/rubric` | The stored rubric, or the default. |
| POST | `/api/assignments/rubric/preview` | Prose → rubric, saving nothing. Costs one API call. |
| POST | `/api/assignments/{id}/solution` | Attach an instructor reference solution (multipart). |

### Submissions
| Method | Path | Description |
|--------|------|-------------|
| POST | `/api/assignments/{id}/submissions` | Upload one or many files (multipart, field `files`). |
| GET | `/api/assignments/{id}/submissions` | List. `?status_filter=` to narrow. |
| GET | `/api/submissions/{id}` | One submission, including its cached parse result. |
| PATCH | `/api/submissions/{id}` | Correct the student name / email / Canvas id. |
| DELETE | `/api/submissions/{id}` | Delete the row, its grade, and the file. |

Upload never fails as a batch. Each file gets its own `ok`/`error`:

```json
{
  "assignment_id": "...", "uploaded": 2, "failed": 1,
  "results": [
    {"filename": "alice_hw3.ipynb", "ok": true,
     "submission_id": "...", "student_name": "Alice Chen"},
    {"filename": "notes.txt", "ok": false,
     "error": "'.txt' is not a supported submission type. Accepted: .htm, .html, .ipynb, .py"}
  ]
}
```

### Grading
| Method | Path | Description |
|--------|------|-------------|
| POST | `/api/assignments/{id}/grade` | Grade submissions. |

Body (all optional):

```json
{"submission_ids": ["..."], "regrade": false, "include_images": true}
```

Runs **synchronously** — one Claude call per submission, roughly 15–40
seconds each. Omit `submission_ids` to grade everything ungraded. Already
graded submissions are skipped unless `regrade` is true; a regrade clears
any previous approval.

A failure on one submission never stops the batch:

```json
{"assignment_id": "...", "graded": 6, "failed": 1, "skipped": 2,
 "results": [{"submission_id": "...", "student_name": "Alice Chen",
              "ok": true, "total_score": 89.0, "percentage": 89.0,
              "letter_grade": "B+", "flags": []}]}
```

### Results
| Method | Path | Description |
|--------|------|-------------|
| GET | `/api/assignments/{id}/results` | All grades. `?flagged_only=true`, `?finalized_only=true`. |
| GET | `/api/submissions/{id}/result` | One grade, with the raw model output. 404 if ungraded. |
| PATCH | `/api/results/{grade_id}/override` | Adjust criterion scores. **409 if finalized.** |
| POST | `/api/results/{grade_id}/finalize` | Approve or un-approve. **Professor only.** |
| GET | `/api/assignments/{id}/stats` | Counts, mean/median, grade distribution. |

Overrides are stored **beside** the AI scores, never over them:

```json
{"overrides": {"model": {"new_score": 45, "note": "Full marks, I was harsh."}},
 "summary_feedback": "Excellent work."}
```

422 if the criterion id is unknown or the score exceeds `max_score`.

### Similarity
| Method | Path | Description |
|--------|------|-------------|
| POST | `/api/assignments/{id}/similarity` | Scan every pair. Body: `{"threshold": 0.5, "clear_existing": true}`. |
| GET | `/api/assignments/{id}/similarity` | Existing flags, highest first. |
| PATCH | `/api/similarity/{flag_id}` | Mark reviewed, attach a note. |

`clear_existing` never removes a flag a professor has already reviewed.

### Export
| Method | Path | Description |
|--------|------|-------------|
| GET | `/api/assignments/{id}/export?format=...` | `csv`, `canvas_csv`, `xlsx`, or `pdf`. Add `&only_finalized=true`. |

### Canvas
| Method | Path | Description |
|--------|------|-------------|
| GET | `/api/canvas/status` | Whether Canvas is configured on this server. |
| GET | `/api/canvas/courses` | Courses the token can teach. |
| GET | `/api/canvas/courses/{id}/assignments` | Assignments in a Canvas course. |
| POST | `/api/assignments/{id}/canvas/sync-roster` | Match submissions to roster students. |
| POST | `/api/assignments/{id}/canvas/push-grades` | Push grades. **Professor only**, finalized-only by default. |

### Health
| Method | Path | Description |
|--------|------|-------------|
| GET | `/api/health` | Public. Reports `anthropic_configured` and `canvas_configured`. |

## Status codes

| Code | Meaning here |
|------|--------------|
| 400 | Malformed request — empty PATCH body, unknown export format, missing Canvas id |
| 401 | Missing, invalid, or expired token |
| 403 | Authenticated but not permitted (TA attempting a professor action) |
| 404 | Not found **or not yours** |
| 409 | Duplicate email; editing a finalized grade |
| 413 | Upload exceeds `MAX_FILE_SIZE_MB` |
| 415 | Unsupported file type |
| 422 | Validation failed — see the `problems` array |
| 501 | Canvas endpoint called with no Canvas configuration |
| 502 | Canvas returned an error |
| 503 | Grading unavailable (missing/rejected API key, rate limit, network) |

Validation errors are flattened for readability:

```json
{"detail": "Request validation failed",
 "problems": [{"field": "email", "message": "value is not a valid email address"}]}
```
